# majan-trainer

麻雀鍛錬。ブラウザで動く麻雀の練習アプリです。スマホでも使えます。

## モード

| モード | 内容 |
|---|---|
| 待ち当て | テンパイの手を見て、待ちをすべて選ぶ（通常／清一色） |
| 何切る | 14枚から、受け入れが最も広くなる牌を切る。全打牌のシャンテン数と受け入れ枚数を表示 |
| 当たり牌読み | 4人の簡易対局をシミュレーションし、リーチがかかった場面で、4人の捨て牌（手出し・ツモ切りつき）から自分の手牌にある当たり牌を当てる。答え合わせでリーチ者の手牌と待ちを公開し、スジ・ノーチャンス・宣言牌の裏スジ／またぎスジなどの読みを解説 |
| 点数計算 | 和了の点数を4択で答える。役・翻数・符の内訳を表示 |

間違えた問題は「復習」に保存され、復習で正解するとリストから消えます。成績と復習リストはブラウザ（localStorage）に保存されます。

### 前提・簡略化しているところ

- 手牌は鳴きなし（門前）のみ
- 点数計算は、裏ドラ・一発・本場・赤ドラ・切り上げ満貫なし
- 受け入れ枚数は、自分の手牌（と切った牌）だけを見えている牌として数える
- 当たり牌読みの対局は鳴きなし。リーチ者は牌効率で打ち、他家は簡易AIで打つ
- 読みの「危険度」は、両面待ちに当たる形がいくつ残るかと、手出し・ツモ切りからの読みを合わせた目安

## Windows で起動する（batファイル）

1. [Git](https://git-scm.com) と [Node.js](https://nodejs.org)（LTS 版）をインストールする
2. `C:\majan` フォルダを作り、`start-majan.bat` をその中に置く
3. `start-majan.bat` をダブルクリックする

初回は `C:\majan\majan-trainer` にアプリをダウンロードし、ブラウザで開きます。2回目以降は最新版を取得してから起動します。
終わるときは、黒い画面（コマンドプロンプト）を閉じます。

## 開発

Node.js 22 以上が必要です。

```sh
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm test           # ロジックのテスト
npm run build      # 型チェック＋本番ビルド（dist/）
```

## 構成

- `src/logic/` 麻雀のロジック（React に依存しない）
  - `tiles.ts` 牌の表現（0〜33 の番号）
  - `shanten.ts` シャンテン数・待ち・受け入れ枚数
  - `scoring.ts` 面子の分解・役・符・点数
  - `danger.ts` 危険度の判定（スジ・ノーチャンス・宣言牌の裏スジ／またぎスジ）
  - `simulate.ts` 当たり牌読み用の4人対局シミュレーション
  - `read.ts` 当たり牌読みの解析（通った牌・牌ごとの読み）
  - `generate.ts` 各モードの問題の生成
- `src/modes/` 各モードの画面
- `src/App.tsx` トップ画面・出題・復習
